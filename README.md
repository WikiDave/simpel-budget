# Simpel Budget

Een simpele budgetplanner in de browser.

- Maak omgevingen aan met een emoji en een naam
- Voeg kosten toe: eenmalig, wekelijks, maandelijks of jaarlijks
- Vul in wat er binnenkomt (inkomsten)
- Vink per kost (en per week) aan wat betaald is
- Zie per maand hoeveel je over hebt

Geen installatie nodig: open `index.html` in je browser, of zet GitHub Pages aan
(Settings → Pages → Deploy from a branch → `main` / root).

Je gegevens worden alleen lokaal in je browser bewaard (localStorage).
